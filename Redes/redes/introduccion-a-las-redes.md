# 📕 Introducción a las redes

Las redes de ordenadores están presentes en casi todo lo que hacemos cada día. Gracias a ellas podemos conectar ordenadores, móviles, impresoras, servidores y otros dispositivos para compartir información y recursos.

Por ejemplo, cuando mandamos un mensaje por WhatsApp, vemos un vídeo, jugamos online, enviamos un correo o buscamos información en Internet, estamos utilizando una red. Algunas redes son pequeñas, como la que tenemos en casa o en el instituto, y otras son enormes, como Internet, que conecta dispositivos de todo el mundo.

Para que todo funcione hacen falta elementos físicos, como cables, fibra óptica, routers, switches o Wi‑Fi, y también elementos lógicos, como las direcciones IP y los protocolos, que permiten que los dispositivos se entiendan entre ellos.cisco+1

Las redes son muy importantes porque nos mantienen conectados y permiten que funcionen muchos servicios actuales, como los bancos online, las tiendas por Internet, las clases virtuales o las aplicaciones de mensajería.
